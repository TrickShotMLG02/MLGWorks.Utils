\section{Event bus}
\label{sec:event-bus}

The static \texttt{EventBus} provides typed publish/subscribe communication without requiring publishers to know their subscribers. An event implements \texttt{IEvent}, which exposes a human-readable \texttt{Name}.

\begin{lstlisting}
using MLGWorks.Utils.Patterns;

public sealed class PlayerDied : IEvent
{
    public string Name => "PlayerDied";
    public string PlayerName { get; }
    public PlayerDied(string playerName) => PlayerName = playerName;
}

IDisposable subscription = EventBus.Subscribe<PlayerDied>(OnPlayerDied);
EventBus.Publish(new PlayerDied("Alice"));
subscription.Dispose();
\end{lstlisting}

\texttt{Subscribe<T>} returns an \texttt{IDisposable}; disposing it removes exactly that subscription and is safe to repeat. \texttt{Unsubscribe<T>} is also available when the original callback is convenient to retain.

During publication the bus iterates over a snapshot, so a callback can dispose its own subscription or add another subscription without invalidating the current delivery. The bus itself is not thread-safe; use it from the Unity main thread.
