\texttt{SceneReference} is a serializable \texttt{ScriptableObject} reference to a scene asset. It exposes the scene path, name, display name, notes, validity, and whether the scene is present in Build Settings.

Create scene-reference assets through the Unity Editor, assign them to fields, and pass them to \texttt{SceneLoader}. Keeping the reference in an asset avoids scattering scene path strings through gameplay code.
