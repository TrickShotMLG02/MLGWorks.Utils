\section{Timer}
\label{sec:timer}

\texttt{MLGWorks.Utils.Helpers.Timer} is a plain C\# countdown timer. It owns no Unity object and advances only when the caller supplies a delta time. That makes it useful in a MonoBehaviour, a service, or a deterministic test.

\subsection{Lifecycle}
\begin{description}[leftmargin=2.8cm,style=sameline]
  \item[\texttt{Start()}] Resets elapsed time and starts the timer.
  \item[\texttt{Pause()}] Freezes a running timer without resetting it.
  \item[\texttt{Resume()}] Continues a paused timer.
  \item[\texttt{Reset()}] Stops the timer and clears elapsed time.
  \item[\texttt{Update(float)}] Advances the timer and fires \texttt{OnFinished} once at the duration.
\end{description}

Useful state is exposed through \texttt{Duration}, \texttt{Elapsed}, \texttt{IsRunning}, \texttt{IsPaused}, and \texttt{IsFinished}.

\begin{lstlisting}
using MLGWorks.Utils.Helpers;
using UnityEngine;

public sealed class RespawnTimer : MonoBehaviour
{
    private readonly Timer timer = new Timer(3f);

    private void Awake()
    {
        timer.OnFinished += Respawn;
        timer.Start();
    }

    private void Update() => timer.Update(Time.deltaTime);

    private void Respawn() => Debug.Log("Respawn is ready.");
}
\end{lstlisting}

\texttt{Start()} always starts from zero. When the timer reaches its duration, it clamps \texttt{Elapsed}, stops running, clears the paused state, and invokes the event.
